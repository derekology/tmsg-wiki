The TMSG Wiki is being built. Suggestions for useful topics, corrections, and improvements are welcome.

## Suggesting a change

Use the **Suggest an edit** link near any page title to open a prefilled GitHub issue for that page. You'll need a GitHub account and must be signed in to submit it; see <a href="https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-an-issue" target="_blank" rel="noopener noreferrer">GitHub's guide to creating an issue</a>. Briefly describe what should change and why, and include links to reliable sources for factual claims, especially information that may change over time.

If you'd rather discuss a change with me directly, <a href="https://www.linkedin.com/in/derekology" target="_blank" rel="noopener noreferrer">please send me a LinkedIn message</a>.

## Writing a page

Use a clear title, organize longer material with descriptive headings, and link to related wiki pages. Separate sourced facts from opinion or interpretation, note uncertainty, and avoid publishing credentials or private information.

Before submitting, check that links work, the page is easy to follow, and its sources support the claims it makes.
