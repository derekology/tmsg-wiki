---
title: Web Personalization
description: How websites adapt content or experiences for different audiences and visitors.
---

Web personalization adapts website content or experiences for a visitor or audience using defined rules and available context. A team might vary a headline, offer, recommendation, or page content for people who meet different criteria. The criteria can be based on contextual signals or governed customer data; the data source and the rules should be clear.

Personalization is not a single technique or a guarantee of relevance. For example, Adobe Target's Experience Targeting evaluates visitors against marketer-defined audience criteria and serves the associated experience. Other tools and implementations may use different rules, data, and delivery methods.

## Design and operate an experience

Start with a customer need and a testable hypothesis, not a desire to customize every page. Define the audience, the experience each audience receives, the data and consent rules involved, and what happens when no rule matches or required data is unavailable. Review how experiences interact so a visitor does not qualify for conflicting changes.

Before launch, test the targeting logic and the full page on relevant devices. Check accessibility, page behavior, performance, and fallback content as well as the intended variation. Use only data suitable for the purpose, with appropriate access and retention controls; personalization can make an otherwise ordinary page reveal information a visitor did not expect to be used.

Keep personalization distinct from experimentation. A targeted experience serves a selected experience to a defined audience; an experiment compares alternatives to learn how they perform. A program can use both, but should document which question it is answering and measure outcomes against a defined baseline or comparison.
